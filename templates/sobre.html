🧴 XAMPU PARA OSSOS

O que é isso?

Um blog minimalista de poesia digital com estética cyberpunk/K-punk. Interface tipo Instagram grid 3x3, temas customizados por post, editor Markdown, e sistema de teasers.

Nascido da fusão entre a poesia romântica gótica e a cultura cibernética contemporânea, este espaço existe para palavras que não cabem em lugar nenhum — exceto aqui.

Funcionalidades

  • Grid 3x3 tipo Instagram com infinite scroll
  • 9 temas customizados por post (cyberpunk, matrix, vaporwave, noir, etc.)
  • Editor Markdown com auto-save e keyboard shortcuts
  • Sistema de teasers: preview automático, imagem ou nenhum
  • Search em tempo real: clique em tags ou digite para filtrar
  • Upload de imagens drag-and-drop para teasers
  • Scroll horizontal para posts largos
  • Toggle Preto/Branco para navegação global

Tech Stack

Backend

  • • Flask (Python 3.10+)
  • • SQLAlchemy ORM
  • • SQLite (dev) / PostgreSQL (prod)
  • • Flask-Login (auth)
  • • Bleach (XSS protection)

Frontend

  • • Vanilla JavaScript
  • • Tailwind CSS (CDN)
  • • marked.js (Markdown)
  • • CSS Custom Properties
  • • IntersectionObserver API

Como Usar

1. Criar Conta

Clique em "Cadastrar Pseudônimo" no menu. Escolha seu username e senha.

2. Criar Post

Clique "+ Novo Post". Escolha título, tema, fonte e tipo de teaser. Escreva em Markdown.

3. Salvar

Ctrl+S ou clique "Salvar Post". Auto-save funciona automaticamente a cada 1s.

4. Buscar

Digite no search bar ou clique em tags para filtrar posts. ESC para limpar.
